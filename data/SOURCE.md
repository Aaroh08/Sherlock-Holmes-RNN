# Dataset provenance

- Title: The Adventures of Sherlock Holmes
- Author: Arthur Conan Doyle
- Source: https://www.gutenberg.org/ebooks/1661
- Download URL: https://www.gutenberg.org/cache/epub/1661/pg1661.txt
- Downloaded for this project: 18 October 2026
- File: `sherlock_holmes.txt`

The downloaded original is preserved with its Project Gutenberg notice and license. The text file describes reuse conditions and directs users outside the United States to check their local copyright rules. Project code licensing does not replace that notice. Cleaning for model input happens in memory; the source file is not rewritten.

Every experiment records the file's SHA-256 hash in `dataset.json`, because the Gutenberg download may be updated over time. The downloader only fetches the file when it is missing.
